## Зачем это

Каждая катушка своя, даже две одинаковых по марке и цвету. Дженерик-профиль —
это отправная точка, а не ответ, и разница между ним и откалиброванным пресетом
— это разница между «печатает обычно нормально» и «печатает предсказуемо».

Загвоздка в том, что честная калибровка — это шесть тестов, у каждого своя
шкала, своя формула и свой способ ошибиться. Руками это значит вести таблицу,
помнить, что поток меряется на финальной температуре, и без опечаток
переносить результаты в нужные поля пресета.

Эту бухгалтерию берёт на себя программа.

- **Знает порядок.** Поток — на финальной температуре, PA — на финальном потоке,
  расход — на финальном PA. Каждая плита готовится с уже найденными значениями,
  поэтому ты меряешь свою катушку, а не дженерик.
- **Не принимает невозможный замер.** Штангель, ошибшийся в десять раз, даёт
  правдоподобное число, которое тихо испортит всё, что напечатается потом. У
  каждой формулы есть границы, и при отказе программа говорит, какая ошибка
  вероятна.
- **Пишет оверлей, а не полный профиль.** Только измеренные поля, остальное
  наследуется — обновление профилей Elegoo не затрёт калибровку.
- **Можно прерваться.** Ответы хранятся по катушкам. Вернёшься через неделю и
  продолжишь.

## Быстрый старт

1. **Скачай и распакуй** [архив для Windows](https://github.com/ValenokMC/Centauri-Carbon-Filament-Calibrator/releases/latest).
2. **Запусти `Настроить.cmd`.** Мастер найдёт OrcaSlicer, профили, твой пресет
   принтера и адрес принтера, если он настроен.
3. **Один раз запусти `Prepare-Templates.cmd`.** Он сгенерирует плиту усадки и
   проведёт через сохранение остальных пяти из штатного мастера калибровки
   OrcaSlicer — [почему так](#о-калибровочных-плитах).
4. **Запусти `Калибровать.cmd`.** Выбери материал и назови катушку.
5. **Проходи плиты.** Печать, замер, число в консоль. Пресет переписывается
   после каждого принятого замера.

Подробно: **[docs/installation.md](docs/installation.md)** ·
По тестам: **[docs/calibration.md](docs/calibration.md)**

## Что калибруется

| № | Тест | Как меряется | Поле пресета |
|---|---|---|---|
| 1 | **Температура** | Лучший блок на башне | `nozzle_temperature` |
| 2 | **Поток** | Самая ровная плитка теста Orca | `filament_flow_ratio` |
| 2б | **Усадка** | Брусок 100 мм штангелем | `filament_shrink` |
| 3 | **Pressure advance** | Самый острый угол на паттерне | `pressure_advance` |
| 4 | **Максимальный расход** | Высота, где полезла недоэкструзия | `filament_max_volumetric_speed` |
| 5 | **Ретракт** | Самый чистый блок на башне | `filament_retraction_length` |

Материалы со шкалами: **PLA · PETG · PETG-CF · PETG-GF · ABS · ASA · PA · TPU**,
у каждого свой базовый профиль и рекомендация по сушке.

## Совместимость

| | Статус |
|---|---|
| Windows 10 / 11 | ✅ Проверено |
| **OrcaSlicer 2.4.2** | ✅ Проверено |
| Другие версии OrcaSlicer | ⚠️ Не проверялось — пути к профилям и имена ключей меняются между версиями |
| Elegoo Centauri Carbon, сопло **0,4 мм** | ✅ Проверено |
| Другие сопла | ❌ Плиты рассчитаны на 0,4; на 0,2 напечатается бессмыслица |
| Centauri Carbon 2, другие принтеры | ❌ Не поддерживается, не проверялось |
| macOS, Linux | ❌ Не поддерживается — везде пути и launcher'ы Windows |
| Другие базовые профили | ❌ Шкалы привязаны к профилям Elegoo |

Всё, что помечено ❌ или ⚠️, — это честное «не проверялось», а не осторожная
формулировка. Иначе кто-то напечатает шесть плит за два дня и получит число,
которое ничего не описывает.

**Язык интерфейса:** русский. Код, документация и шаблоны issue — английские.

## Безопасность

Программа пишет ровно в одно место за пределами своего каталога данных — в папку
пресетов филамента OrcaSlicer. Это самое опасное, что она делает, поэтому:

- **Точный путь показывается, и ты подтверждаешь** — до того, как что-то
  произойдёт.
- **Существующий пресет сначала копируется** в `preset-backups\` с меткой
  времени.
- **JSON проверяется, пишется во временный файл и переносится на место.** Сбой
  на любом шаге оставляет оригинал нетронутым. На это есть тест.
- **`Dry-Run.cmd` не пишет вообще ничего** — можно пройти весь диалог и увидеть,
  что бы произошло.

**OrcaSlicer никогда не убивается принудительно.** Её вежливо просят закрыться, и
если она висит на диалоге о несохранённом проекте, калибратор останавливается и
просит разобраться вручную. `taskkill /F` выбросил бы часы твоей работы ради
экономии одного перезапуска.

Подробнее: [docs/security.md](docs/security.md)

## О калибровочных плитах

Пять плит из шести на материал — это **штатные модели мастера калибровки
OrcaSlicer**. Модели хорошие: на блоках подписи, есть настоящие тестовые фичи —
мосты, нависания, ниточные переходы. Голые коробки были бы хуже во всём.

Их лицензия нигде явно не указана, поэтому здесь они **не публикуются**. Вместо
этого:

- `Prepare-Templates.cmd` проводит через один прогон мастера Orca и сохранение
  результата. Сохранённое обезличивается — вычищаются адрес принтера и личные
  имена пресетов — и кладётся в твой каталог данных.
- **Плита усадки генерируется с нуля** кодом этого проекта и поэтому лежит в
  `templates/`.
- Плиты, которые ты собрал, — твои, на твоей машине, из слайсера, который у тебя
  и так есть.

Это десять минут, один раз. Так честно.

Подробно: [docs/templates.md](docs/templates.md)

## Где твои данные

```
%LOCALAPPDATA%\CentauriCarbonFilamentCalibrator\
├── config.json          что нашёл мастер настройки
├── Journal.csv          строка на каждую откалиброванную катушку
├── spools\              замеры по катушкам и прогонам
├── templates\           собранные тобой плиты
├── generated-plates\    твои персональные копии
├── preset-backups\      каждый заменённый пресет, с меткой времени
└── logs\
```

Вне папки программы — обновление ничего не затронет. Ничего отсюда не
публикуется; `examples/Journal.example.csv` в репозитории целиком выдуман.

## Если что-то не работает

| Симптом | Скорее всего |
|---|---|
| OrcaSlicer не найдена | Установлена в необычное место — в `Настроить.cmd` можно указать путь. |
| Базовый профиль не найден | В Orca не установлены профили вендора Elegoo. |
| Пресет не появился | Orca читает пресеты при старте. Перезапусти её. |
| Пресет есть, но не выбирается | Он совместим с известными ему пресетами принтера; перезапусти `Настроить.cmd` после добавления пресета. |
| Замер отклонён | Обычно правильно. Прочитай сообщение — там сказано, какая ошибка вероятна. |
| Плита печатается не тем филаментом | Шаблоны ещё не собраны — `Prepare-Templates.cmd`. |

Начни с **`Doctor.cmd`** — он только читает, ничего не меняет и печатает всё,
что программа видит.

Полное руководство: [docs/troubleshooting.md](docs/troubleshooting.md)

## Разработка

```bash
git clone https://github.com/ValenokMC/Centauri-Carbon-Filament-Calibrator.git
cd Centauri-Carbon-Filament-Calibrator
python -m pip install -r requirements-dev.txt
python -m pytest tests/ -q
python tools/check_public_safety.py
```

Тесты не трогают настоящую установку OrcaSlicer, не пишут в настоящий
`%LOCALAPPDATA%` и не закрывают запущенный слайсер — на каждое из этих действий
в тестах стоит заглушка, которая падает.

См. [CONTRIBUTING.md](CONTRIBUTING.md) и [docs/architecture.md](docs/architecture.md).
