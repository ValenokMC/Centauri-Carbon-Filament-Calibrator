## OrcaSlicer

[OrcaSlicer](https://github.com/SoftFever/OrcaSlicer) is licensed under
**AGPL-3.0**.

**No OrcaSlicer code is included, linked, or redistributed in this project.**
The calibrator is a separate program that reads OrcaSlicer's configuration
files, writes a preset file into its profile folder, and launches it the way any
program launches another. It does not import, embed, or derive from its source.

### The calibration plate models

This is the part worth reading.

Five of the six plates per material — temperature tower, flow test, pressure
advance pattern, max volumetric flow tower, retraction tower — are **OrcaSlicer's
own calibration models**, produced by its built-in calibration wizard.

Those models ship with OrcaSlicer. The terms under which they may be
**redistributed separately from OrcaSlicer** are not stated anywhere this
project can point to.

Rather than guess, this project does not redistribute them:

- The user starts each test directly from Orca's own live Calibration menu.
- The generated tower/pattern is sliced and printed in that live session. No
  Orca model is copied into this repository or a release archive.
- Saved wizard projects are deliberately not imported or reopened: an ordinary
  3MF does not preserve Orca's active calibration parameters.

**If you maintain OrcaSlicer** and would like to clarify the terms for these
models one way or the other, please
[open an issue](https://github.com/ValenokMC/Centauri-Carbon-Filament-Calibrator/issues).

### The shrinkage plate

It is generated by `src/centauri_calibrator/geometry.py` — a 100 × 10 × 3 mm
bar built vertex by vertex. It is this project's own work, ships as bare
geometry in `templates/`, and is covered by this project's [MIT licence](LICENSE).
The user selects the current spool preset in Orca before slicing it.

## Elegoo profiles

The Elegoo filament and process profiles are installed as part of OrcaSlicer and
belong to their authors. The calibrator **reads** them to find base values and
to follow the `inherits` chain. It does not copy them into this repository, and
it does not include their contents in a release.

The preset it writes is an **overlay**: it names an Elegoo profile in its
`inherits` field and adds only the measured values. It contains no Elegoo
profile content — which is also why an Elegoo profile update does not wipe a
calibration.
