# Third-party notices

Filament Lab runs inside OrcaSlicer and uses a few libraries for mesh work. This
file says precisely what is and is not redistributed here.

## OrcaSlicer and its calibration models

[OrcaSlicer](https://github.com/SoftFever/OrcaSlicer) is licensed under
**AGPL-3.0**. No OrcaSlicer code is included in this repository or in a release.
The plugin talks to Orca only through Orca's own plugin API.

The temperature tower, flow tiles, pressure-advance tower and max-flow tower are
**OrcaSlicer's own calibration models**. They are **not copied into this
repository or into a release**. At run time the plugin reads them from the
OrcaSlicer installation on the user's computer
(`resources/calib/…`), places them on a plate and saves the plate in the user's
own data folder. Nothing derived from them leaves that computer through this
project.

The **shrinkage bar** (100 × 10 × 3 mm) is generated by `plugin/модели.py`. It is
this project's own work under the [MIT licence](LICENSE).

## Elegoo and other vendor profiles

Vendor filament, process and printer profiles ship with OrcaSlicer and belong to
their authors. The plugin reads values from them and writes presets that name a
base profile in `inherits` and add only the measured values. No vendor profile
content is copied into this repository.
