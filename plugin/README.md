# Filament Lab

Панель калибровки филамента для OrcaSlicer. Название репозитория для выпуска — OrcaSlicer Calibration Plugins.

Ветка плагина для OrcaSlicer 2.5, предварительная сборка для Windows.

[Текущее состояние и план продолжения](СОСТОЯНИЕ.md).

## Сборка

```powershell
python plugin/build.py dist/kalibrovka.py
```

Orca устанавливает файл через меню «Плагины → Установить локальный плагин».
Сборка объявляет зависимости для обработки сеток в метаданных плагина.
Температурная башня, плитки потока, башня PA и башня расхода используют модели
из установленной OrcaSlicer. Для теста усадки используется брусок 100 мм.
Откат — необязательный тест после пяти основных. В его карточке есть настройки
для штатного теста «Калибровка → Откат» и поле для сохранения замера.

При создании катушки плагин предлагает совместимый профиль выбранного материала.
При открытии плиты плагин пытается назначить пресет катушки первому слоту Orca.
Если Orca не позволяет сменить профиль автоматически, выбери его в первом слоте вручную.
Плита использует первый слот. Настройки остальных филаментов сохраняются.
Плагин создаёт 3MF с геометрией и настройками теста поверх выбранных
профилей. Внешние настройки принтера в 3MF не записываются.

## Проверки на OrcaSlicer 2.5.0 для Windows

- Пакетная нарезка 40 плит, пять тестов на каждом из восьми материалов. Для CLI
  параметры опубликованной плиты накладывались на копию обычного 3MF.
- Из тестового окна Orca с двумя филаментами проверены G-code температурной
  башни PETG (250 → 225 °C) и башни расхода (ваза, 24,99 из 25 мм³/с).
- В чистом профиле Prusa MINI создан пресет катушки поверх Generic PLA High Speed.
  Температурная башня нарезалась с процессом Prusa и шкалой 230 → 195 °C.
- Скопированные данные прежней версии читаются, включая четыре замера PA.
- Перед релизом остаются штатная установка из файла на чистом профиле и
  реальная калибровка катушки.
