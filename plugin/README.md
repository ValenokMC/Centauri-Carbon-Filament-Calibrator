# Калибровка филамента для OrcaSlicer

Ветка плагина для OrcaSlicer 2.5, предварительная сборка для Windows.

## Сборка

```powershell
python plugin/build.py dist/kalibrovka.py
```

Orca устанавливает файл через меню «Плагины → Установить локальный плагин».
Сборка объявляет зависимости для обработки сеток в метаданных плагина.
Температурная башня, плитки потока, башня PA и башня расхода используют модели
из установленной OrcaSlicer. Для теста усадки используется брусок 100 мм.
Откат запускается из штатного меню калибровки Orca.

Для новой катушки выбери исходный пресет филамента в первом слоте Orca.
После создания катушки выбери её пресет там же перед загрузкой плиты.
Плагин создаёт 3MF с геометрией и настройками теста поверх выбранных
профилей. Внешние настройки принтера в 3MF не записываются.
